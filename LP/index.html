{{ t.faq.title }}

1. Quanto tempo leva para entregar uma Landing Page ou Sistema? {{ faq1Open ? '−' : '+' }}
Landing Pages de alta conversão costumam ser entregues em prazos ágeis de 5 a 10 dias úteis. Sistemas web e aplicativos sob medida variam conforme o escopo (geralmente entre 15 a 45 dias). Todo o cronograma é alinhado antes do início.
2. Terei custos mensais ou o código é 100% meu? {{ faq2Open ? '−' : '+' }}
O código fonte e todos os acessos são 100% seus! Não cobro mensalidades ocultas pelo desenvolvimento. Os únicos custos recorrentes são a hospedagem/domínio da sua escolha (geralmente poucos reais por mês ou planos gratuitos para início).
3. Como funciona o suporte após o lançamento? {{ faq3Open ? '−' : '+' }}
Todos os projetos acompanham 30 dias de garantia e suporte técnico completo para tirar dúvidas, ajustar detalhes e garantir que tudo opere com estabilidade máxima.
4. Quais são as formas de pagamento aceitas? {{ faq4Open ? '−' : '+' }}
Aceito PIX (com desconto especial à vista) e parcelamento no cartão de crédito em até 12x, com emissão de contrato claro e transparente para ambas as partes.
